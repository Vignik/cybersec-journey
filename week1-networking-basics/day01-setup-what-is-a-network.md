# Day 1: Setup + What is a Network?

## 📖 Topic
Getting tools ready (GitHub, VirtualBox, TryHackMe) and understanding the
core idea of networking before diving into technical layers.

## 🧠 Key Concepts

- **A network** is two or more devices connected together so they can share
  data and resources.
  *Example: your laptop and phone both connecting to the same Wi-Fi router
  can send files to each other or both reach the internet.*

- **Nodes** are any device on a network (computer, phone, printer, router).

- **A connection** just means there's a physical or wireless path (cable,
  Wi-Fi radio signal) plus an agreed-upon set of rules (a *protocol*) so the
  devices understand each other.
  *Example: two people speaking different languages standing next to each
  other aren't "connected" in any useful way — they need a shared language.
  Devices need a shared protocol (like TCP/IP) the same way.*

- **LAN vs WAN**:
  - LAN (Local Area Network) — devices in one building/home (your home Wi-Fi)
  - WAN (Wide Area Network) — networks spanning large distances (the internet
    itself is the biggest WAN)
