# Day 15: Install Linux (Kali/Ubuntu) in VirtualBox

## 📖 Topic
Getting a Linux VM up and running, and understanding what the terminal
actually is.

## 🧠 Key Concepts

- **VM (Virtual Machine)**: a software-emulated computer running inside
  your real computer, isolated from your host OS. Safe place to practice
  Linux/security tools without risking your main system.

- **Kali vs Ubuntu**: Kali is a security-focused distro pre-loaded with
  pentesting tools; Ubuntu is a general-purpose, beginner-friendly distro.
  Either works for learning Linux fundamentals — Kali is useful once you
  get into tool-based work (Nmap, Burp Suite, etc.)

- **The terminal**: a text interface to talk directly to the OS via
  commands, instead of clicking through a GUI. Faster, scriptable, and
  how most Linux administration/security work actually happens.

- **Shell**: the program that interprets your terminal commands (e.g. Bash
  — the most common Linux shell).
